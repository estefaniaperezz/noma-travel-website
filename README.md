# NOMA — Travel Studio

NOMA is a cinematic editorial travel website concept focused on immersive destination storytelling rather than conventional booking flows.

**Live demo:** https://noma-travel.netlify.app/

## Highlights

- Responsive editorial layouts across desktop, tablet and mobile
- Scroll-driven destination transitions
- Interactive Explore states for featured destinations
- Smooth scrolling and motion choreography
- Reduced-motion support
- Photography-led art direction with destination-specific visual treatments

## Built with

- React
- Vite
- GSAP
- ScrollTrigger
- Lenis
- CSS

## Project structure

```text
public/        Static assets and photography
src/
  components/  UI and editorial sections
  hooks/       Interaction and motion logic
  lib/         Shared animation and scroll utilities
  styles/      Global styles and design tokens
```

## Development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```
